# tienda-gaming

MVP de e-commerce gaming/PC — catálogo, carrito, checkout mock, login y panel admin.

Proyecto separado de [fde-intro](https://github.com/ramirogauto/fde-intro) (cuaderno de aprendizaje FDE).

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS

## Desarrollo local

```bash
npm install
npm run dev
```

Abrí [http://localhost:3000](http://localhost:3000).
